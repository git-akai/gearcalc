Gear Calculator
* This portion is for aiding in gear design with a focus on individual gear geometry.
* The main functions exist for creating new designs for export into CAD or an engineering drawing.
* The intended usage pattern is to take inputs (gear parameters) and output other parameters, as well as a 2D representation of the gear.
	Gear Tab
	* Tabs represent different gears, of which there can be an arbitrary number of.
	* Each separate gear can have a name, displayed in the sidebar. Names do not need to be unique.
	* Gears can be created, copied, and deleted.
	* Every tab has the same high level structure:
		* Gear name
		* Copy, create new, and delete gear.
			"Copy" creates a new, duplicate, tab with the same information (including name) from the tab where the copy button was used.
			"Delete" deletes the tab where the delete button was used. A classic "Are you sure?" dialog prevents accidental usage. Deleting the last remaining tab also automatically creates a new blank tab/gear with the default values (same function as create new).

Geartrain Calculator
* This portion is for aiding in geartrain design with a focus on system level analysis, rather than completely comprehensive individual gear design.
* The main functions exist for creating new designs, for modifying existing designs, or for deriving allowables from known designs.
* The intended usage pattern is to take inputs (torques, material properties, etc) and allow the user to easily and freely create an arbitrary number of gear stages that produce the desired outputs, while automatically calculating many common intermediate parameters to aid in decision making.
	Geartrain Tab
	* Tabs represent different geartrains, of which than can be an arbitrary number of.
	* Each separate geartrain can have a name, displayed in the sidebar. Names do not need to be unique.
	* Geartrains can be created, copied, exported, imported, and deleted.

			* Geartrain name
			* Export, import, copy, create new, and delete geartrain.
				"Export" creates a human read-able text file containing the information of the tab/geartrain.
				"Import" takes a file of the type above and creates a new tab, filling it with the information. This is a read-only operation for the file; to save changes the export function  must be used - no state is saved within the program between uses.
				"Copy" creates a new, duplicate, tab with the same information (including name) from the tab where the copy button was used.
				"Delete" deletes the tab where the delete button was used. A classic "Are you sure?" dialog prevents accidental usage. Deleting the last remaining tab also automatically creates a new blank tab/geartrain with the default values (same function as create new).
